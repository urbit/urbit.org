# Nockchain

The protocol for verifiable compute networks, built as the first ZK-Proof-of-Work (zkPoW) blockchain.

[Nockchain](https://nockchain.org) is a ZK-Proof-of-Work blockchain that turns verifiable computation into a tradable commodity — programmable gold backed by useful compute. Built on Nock, Urbit's famously simple low-level instruction set, it is already the largest proving network in the world.
